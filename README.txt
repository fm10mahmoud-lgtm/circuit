1) اعمل حساب على github.com (مجاني) واعمل Repository جديد.
2) ارفع كل محتويات الفولدر ده (بما فيه فولدر .github) على الـ Repository.
3) افتح تبويب Actions > Build APK > استنى حوالي 3-5 دقايق.
4) افتح آخر تشغيل ونزّل circuit-app-apk (جواه app-debug.apk).
5) انقل الملف للموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة").
